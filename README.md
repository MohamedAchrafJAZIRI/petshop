# 🐾 PetShop - Mini Site Web

## 📌 Description du projet
PetShop est un mini-site web statique développé en HTML et CSS.
Il présente une boutique en ligne spécialisée dans les produits 
pour animaux de compagnie (chiens, chats et poissons).
Ce projet a été développé dans le cadre du module Problem Solving
en utilisant Git et GitHub comme outils de gestion de versions.

## 🚀 Étapes d'installation

1. Cloner le dépôt :
```bash
git clone https://github.com/MohamedAchrafJAZIRI/petshop.git
```

2. Accéder au dossier :
```bash
cd petshop
```

3. Ouvrir le fichier dans le navigateur :
```
html/home.html
```

---

## 🌿 Workflow Git utilisé

### Stratégie de branches :
- `main` → version stable finale du projet
- `develop` → branche d'intégration
- `feature-header` → développement du header
- `feature-hero` → développement de la section hero
- `feature-about` → développement de la section about
- `feature-categories` → développement des catégories
- `feature-products` → développement des produits
- `feature-products-v2` → correction et ajout du 5ème produit
- `feature-footer` → développement du footer
- `feature-footer-bottom` → section bas de footer

---

## ⚙️ Commandes Git utilisées
```bash
# Cloner le dépôt
git clone https://github.com/MohamedAchrafJAZIRI/petshop.git

# Changer de branche
git checkout develop

# Créer une nouvelle branche
git checkout -b feature-header

# Ajouter les modifications
git add .

# Commiter les modifications
git commit -m "feat: add header with logo and navigation"

# Envoyer les modifications
git push origin feature-header

# Récupérer les modifications
git pull origin develop

# Fusionner les branches
git merge develop

# Synchroniser develop avec main
git merge main -m "fix: sync develop with main"
```
